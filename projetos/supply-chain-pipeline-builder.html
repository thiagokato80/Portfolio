Supply Chain Pipeline Builder

Construtor visual de pipelines de análise e previsão de demanda

Ferramenta no-code onde o analista monta fluxos de dados conectando cards num canvas — ETL, classificação de estoque, simulação de Monte Carlo e previsão de séries temporais — e exporta o pipeline pronto como script Python.

O problema

Análise de supply chain vive numa terra de ninguém: complexa demais para planilha, específica demais para uma ferramenta de BI, e frequente demais para virar projeto de engenharia de dados toda vez.

O analista que sabe a regra do negócio — como classificar o estoque, que nível de serviço usar, o que é sazonalidade e o que é ruído — geralmente não escreve o Python que faz a conta. E quem escreve o Python não conhece a regra.

A solução

Um canvas onde cada card é uma operação e as conexões são o fluxo de dados. As colunas disponíveis são detectadas automaticamente do card anterior, e cada etapa mostra a prévia do resultado — o analista vê a transformação acontecendo, não descobre o erro no fim.

  • 15 operações de ETL — filtro, cálculo com condicional, junção, agregação, pivot, datas, texto, deduplicação, união, conversão de tipo, tratamento de nulos.
  • Análise de estoque — classificação ABC/XYZ, estoque de segurança, ponto de reposição e lote econômico, com conversão automática de período.
  • Monte Carlo para estoque de segurança otimizado por custo, sobre mais de 10.000 simulações.
  • Previsão — média móvel simples, ponderada e exponencial, mais ARIMA/SARIMA com banda de confiança e suporte por grupo, com métricas de acurácia MAE, RMSE e MAPE.
  • Validação antes de executar, com checagem local instantânea e análise profunda no backend, apontando o card exato de cada problema.
  • Exportação como código — qualquer pipeline vira script Python ou notebook Jupyter executável, gerado inteiramente no navegador.

A exportação como código é a decisão de produto mais importante: a ferramenta não aprisiona o trabalho. O que foi montado no canvas sai como Python legível, que roda sem ela.

Capítulo atual: integração de demanda planejada

A frente em desenvolvimento hoje conecta o Pipeline Builder a um sistema corporativo de planejamento, para que a previsão deixe de ser um exercício isolado e passe a alimentar a demanda planejada da operação.

É a transição que mais interessa no projeto: sair de ferramenta de análise, onde o resultado é um gráfico que alguém interpreta, para componente de sistema, onde o resultado é um número que outro processo consome — com o rigor de contrato de dados e reprodutibilidade que isso exige.

Resultado

Análises que dependiam de um desenvolvedor disponível passaram a ser montadas por quem conhece a regra de negócio. E o pipeline montado no canvas não fica preso à ferramenta: sai como código.
