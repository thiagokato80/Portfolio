O que é um outlier

Um outlier — também conhecido como valor atípico, ponto fora da curva ou dado discrepante — é uma observação que se desvia significativamente dos demais valores de um conjunto. Essa discrepância pode ser causada por erros de medição, eventos raros ou características únicas daquela observação.

O efeito é mais violento do que a intuição sugere:

MedidaDados sem outlier
1, 2, 3, 3, 4, 5, 4		Dados com outlier
1, 2, 3, 3, 4, 5, 400
Média3,1459,714
Mediana33
Desvio padrão1,345150,057

Um único valor mudou a média de 3,14 para 59,71 — e a estimativa inteira junto. A mediana, note, não se moveu.

Um exemplo do mundo real

Em uma empresa de 50 funcionários, 45 pessoas ganham R$ 6.000 mensais e 5 profissionais seniores ganham R$ 100.000 cada. O salário médio da empresa é de R$ 15.400 — um número que leva à conclusão errada, já que a maioria absoluta ganha muito menos que isso.

A mediana, por sua vez, é R$ 6.000: bem mais representativa do que a média. Por essa razão, diante de outliers, a mediana costuma ser a medida mais apropriada.

Outlier é terminologia comum entre analistas e cientistas de dados justamente porque exige muita atenção — caso contrário, resulta em estimativas totalmente erradas.

Origem dos outliers

  • Erros no input de dados: erros humanos durante a coleta, gravação ou digitação.
  • Erro de medição: a fonte mais comum. Causado quando o instrumento de medição utilizado apresenta defeito.
  • Outlier natural: quando o valor atípico não é artificial, isto é, não decorre de erro. A maioria dos dados do mundo real pertence a esta categoria.

Identificando outliers: oito técnicas

Existem diversos métodos para identificar outliers, cada um com vantagens e desvantagens. Os mais comuns caem em três famílias: análise visual, testes estatísticos e algoritmos de detecção.

  1. Teste de hipótese (teste de Grubbs)
  2. Método Z-score
  3. Z-score robusto
  4. Método IQR
  5. Winsorização (limite de percentil)
  6. Categorização DBSCAN
  7. Isolation Forest
  8. Visualização de dados

1. Teste de Grubbs

O teste de Grubbs, também conhecido como teste de Dixon unilateral, é um método estatístico para detectar outliers em conjuntos de dados unidimensionais. Destaca-se por simplicidade, eficiência e robustez, sendo usado em análise de dados científicos, controle de qualidade, análise financeira e análise de pesquisas.

O teste é definido para as hipóteses:

  • H₀: não há outliers no conjunto de dados.
  • H₁: há exatamente um outlier no conjunto de dados.

A estatística é G = max|Xᵢ − X̄| / SD, onde X̄ e SD são a média e o desvio padrão da amostra. Se o valor calculado for maior que o crítico, rejeita-se a hipótese nula.

import numpy as np
import scipy.stats as stats

x = np.array([12, 13, 14, 19, 21, 23])
y = np.array([12, 13, 14, 19, 21, 23, 45])

def grubbs_test(x):
    n = len(x)
    mean_x = np.mean(x)
    sd_x = np.std(x)
    numerator = max(abs(x - mean_x))
    g_calculated = numerator / sd_x
    print("Valor calculado do Grubbs:", g_calculated)
    t_value = stats.t.ppf(1 - 0.05 / (2 * n), n - 2)
    g_critical = ((n - 1) * np.sqrt(np.square(t_value))) / (np.sqrt(n) * np.sqrt(n - 2 + np.square(t_value)))
    print("Valor crítico do Grubbs:", g_critical)
    if g_critical > g_calculated:
        print("Calculado menor que o crítico: aceitamos H0, não existe outlier")
    else:
        print("Calculado maior que o crítico: rejeitamos H0, existe um outlier")

grubbs_test(x)
grubbs_test(y)

Para x: calculado 1,427 contra crítico 1,887 — aceita-se H₀, não há outlier. Para y: calculado 2,277 contra crítico 2,020 — rejeita-se H₀, existe um outlier.

2. Método Z-score

Com o Z-score identificamos dados que estão a X desvios padrão de distância da média. Sob a curva normal:

  • 68% dos pontos estão entre −1 e +1 desvio padrão;
  • 95% entre −2 e +2 desvios padrão;
  • 99,7% entre −3 e +3 desvios padrão.

A fórmula é Z = (X − média) / desvio padrão. Se o Z-score de um dado for superior a 3 — fora dos 99,7% —, o valor é bastante diferente dos demais e pode ser considerado outlier.

import pandas as pd
import numpy as np

train = pd.read_csv('dataset/train.csv')
out = []

def Zscore_outlier(df):
    m = np.mean(df)
    sd = np.std(df)
    for i in df:
        z = (i - m) / sd
        if np.abs(z) > 3:
            out.append(i)
    print("Outliers:", out)

Zscore_outlier(train['LotArea'])

3. Z-score robusto

Também chamado de método do desvio absoluto da mediana. É semelhante ao Z-score, com uma mudança importante nos parâmetros: como média e desvio padrão são fortemente influenciados por outliers, trocamos ambos por mediana e desvio absoluto da mediana.

A fórmula é R.Z = 0,6745 × (Xᵢ − mediana) / MAD, onde MAD = mediana(|X − mediana|).

A constante 0,6745 aparece porque, se X segue uma distribuição normal padrão, o MAD converge para a mediana da meia distribuição normal — o percentil 75%, que vale aproximadamente 0,6745.

import pandas as pd
import numpy as np
import scipy.stats as stats

train = pd.read_csv('dataset/train.csv')
out = []

def ZRscore_outlier(df):
    med = np.median(df)
    ma = stats.median_abs_deviation(df)
    for i in df:
        z = (0.6745 * (i - med)) / np.median(ma)
        if np.abs(z) > 3:
            out.append(i)
    print("Outliers:", out)

ZRscore_outlier(train['LotArea'])

Note que o método robusto detecta muito mais outliers que o Z-score simples no mesmo conjunto — exatamente porque a média e o desvio padrão do primeiro já haviam sido contaminados pelos valores extremos.

4. Método IQR

Aqui detectamos outliers usando quartis. O intervalo interquartil informa a variação do conjunto: qualquer valor fora do intervalo de −1,5 × IQR a +1,5 × IQR é tratado como discrepante.

  • Q1 representa o primeiro quartil, 25% dos dados.
  • Q2 representa o segundo quartil, a mediana, 50% dos dados.
  • Q3 representa o terceiro quartil, 75% dos dados.
  • Q1 − 1,5 × IQR e Q3 + 1,5 × IQR delimitam os valores aceitáveis.
import pandas as pd
import numpy as np

train = pd.read_csv('dataset/train.csv')
out = []

def iqr_outliers(df):
    q1 = df.quantile(0.25)
    q3 = df.quantile(0.75)
    iqr = q3 - q1
    lower_tail = q1 - 1.5 * iqr
    upper_tail = q3 + 1.5 * iqr
    for i in df:
        if i > upper_tail or i < lower_tail:
            out.append(i)
    print("Outliers:", out)

iqr_outliers(train['LotArea'])

5. Winsorização (limite de percentil)

A winsorização, também conhecida como transformação de Tukey, substitui os outliers por valores mais próximos da mediana, preservando a forma geral da distribuição e reduzindo o impacto dos extremos nas análises.

O método é semelhante ao IQR. Aqui, por exemplo, identificamos como outliers os valores fora da faixa entre o percentil 1 e o percentil 99.

import pandas as pd
import numpy as np

train = pd.read_csv('dataset/train.csv')
out = []

def Winsorization_outliers(df):
    q1 = np.percentile(df, 1)
    q3 = np.percentile(df, 99)
    for i in df:
        if i > q3 or i < q1:
            out.append(i)
    print("Outliers:", out)

Winsorization_outliers(train['Fare'])

6. DBSCAN

O DBSCAN (Density-Based Spatial Clustering of Applications with Noise) é um algoritmo de agrupamento baseado em densidade. Destaca-se por duas capacidades:

  • Encontrar clusters de formas e tamanhos diversos: ao contrário de métodos que assumem formas predefinidas, o DBSCAN detecta clusters irregulares, adaptando-se aos dados.
  • Lidar com ruído: identifica e separa pontos que não pertencem a nenhum cluster, o que o torna ideal para conjuntos com outliers.

O algoritmo opera com dois parâmetros: eps, a distância máxima entre pontos de um mesmo cluster, e MinPts, o número mínimo de pontos para formar um cluster. O cluster -1 é o que contém os valores discrepantes.

Como funciona

Pontos centrais e de borda: o DBSCAN começa identificando pontos centrais — os que possuem ao menos MinPts vizinhos dentro de um raio eps. Pontos de borda estão na vizinhança de um ponto central, mas não têm vizinhança própria suficiente.

Expansão: cada ponto central forma um cluster inicial, expandido iterativamente ao agregar pontos de borda.

Ruído: pontos que não podem ser agregados a nenhum cluster são classificados como ruído.

O DBSCAN fornece o melhor resultado para detecção de outliers multivariados.

from sklearn.cluster import DBSCAN
import pandas as pd

train = pd.read_csv('dataset/train.csv')

def DB_outliers(df):
    outlier_detection = DBSCAN(eps=2, metric='euclidean', min_samples=5)
    clusters = outlier_detection.fit_predict(df.values.reshape(-1, 1))
    data = pd.DataFrame()
    data['cluster'] = clusters
    print(data['cluster'].value_counts())

DB_outliers(train['Fare'])

No conjunto de 891 registros, o cluster -1 reuniu 32 pontos — os discrepantes.

7. Isolation Forest

É um algoritmo de aprendizado de máquina não supervisionado para detectar anomalias. Aplica-se a detecção de fraude, detecção de intrusão, manutenção preditiva, análise de imagens e detecção de anomalias médicas.

Como funciona

Construção de árvores aleatórias: o algoritmo constrói um conjunto de árvores de decisão de forma aleatória, dividindo os dados a cada nó, com recurso e valor de divisão escolhidos ao acaso.

Isolamento de anomalias: o Isolation Forest isola anomalias mais rapidamente do que observações normais. Pontos isolados em níveis mais rasos da árvore são mais propensos a ser anomalias.

Pontuação: cada ponto recebe uma pontuação com base no comprimento médio do caminho percorrido para isolá-lo em todas as árvores.

No modelo abaixo, resultado -1 significa que o ponto é discrepante; 1, que não é.

from sklearn.ensemble import IsolationForest
import numpy as np
import pandas as pd

train = pd.read_csv('dataset/train.csv')
train['Fare'].fillna(train[train.Pclass == 3]['Fare'].median(), inplace=True)

def Iso_outliers(df):
    iso = IsolationForest(random_state=1, contamination='auto')
    preds = iso.fit_predict(df.values.reshape(-1, 1))
    data = pd.DataFrame()
    data['cluster'] = preds
    print(data['cluster'].value_counts().sort_values(ascending=False))

Iso_outliers(train['Fare'])

Resultado: 706 pontos normais contra 185 discrepantes.

8. Visualização de dados

A visualização é útil para limpeza, exploração, detecção de discrepantes e grupos incomuns, e identificação de tendências e clusters. Os gráficos mais usados para detectar outliers são o box plot, o gráfico de dispersão, o histograma, o gráfico de distribuição e o QQ plot.

import pandas as pd
import seaborn as sns
from matplotlib import pyplot as plt
from statsmodels.graphics.gofplots import qqplot

train = pd.read_csv('dataset/train.csv')

def box_plots(df):
    plt.figure(figsize=(10, 4))
    plt.title("Box Plot")
    sns.boxplot(df)
    plt.show()

def hist_plots(df):
    plt.figure(figsize=(10, 4))
    plt.hist(df)
    plt.title("Histograma")
    plt.show()

def scatter_plots(df1, df2):
    fig, ax = plt.subplots(figsize=(10, 4))
    ax.scatter(df1, df2)
    ax.set_xlabel('Age')
    ax.set_ylabel('Fare')
    plt.title("Gráfico de dispersão")
    plt.show()

def qq_plots(df):
    plt.figure(figsize=(10, 4))
    qqplot(df, line='s')
    plt.title("Normal QQ Plot")
    plt.show()

Tratamento: o que fazer depois de detectar

A presença de outliers pode distorcer a média e outras medidas de tendência central, aumentar a variância e outras medidas de dispersão — fazendo os dados parecerem mais dispersos do que são — e afetar a significância estatística dos testes, levando a conclusões errôneas.

A maioria dos algoritmos de aprendizado de máquina não funciona bem na presença de valores discrepantes. Há quatro técnicas para lidar com eles.

1. Exclusão

Excluímos outliers quando decorrem de erro de entrada, erro de processamento, ou quando são muito poucos. Também é possível usar o corte em ambas as extremidades. Mas excluir observações não é boa ideia em conjuntos de dados pequenos — e é importante remover apenas os outliers genuínos, não dados válidos.

def drop_outliers(df, field_name):
    iqr = 1.5 * (np.percentile(df[field_name], 75) - np.percentile(df[field_name], 25))
    df.drop(df[df[field_name] > (iqr + np.percentile(df[field_name], 75))].index, inplace=True)
    df.drop(df[df[field_name] < (np.percentile(df[field_name], 25) - iqr)].index, inplace=True)

2. Transformação

Transformar variáveis também elimina valores discrepantes, reduzindo a variação causada pelos extremos. As opções são dimensionamento, transformação logarítmica, raiz cúbica e transformação Box-Cox.

Essas técnicas convertem valores do conjunto em valores menores e ajudam a normalizar dados com muitos extremos ou distorcidos. Não há perda de dados. Nem sempre oferecem os melhores resultados — mas, entre elas, a transformação Box-Cox costuma dar o melhor.

# Box-Cox
import scipy

train['Rent Index'], fitted_lambda = scipy.stats.boxcox(train['Rent Index'], lmbda=None)

3. Substituição

Podemos substituir os valores discrepantes por média, mediana ou zero. Como estamos substituindo, não há perda de dados — e a mediana costuma ser apropriada porque não é afetada por valores discrepantes.

A prática, também conhecida como imputação, exige cautela. Os impactos:

  • Redução do efeito dos outliers: minimiza distorções na média, mediana e desvio padrão, que por sua vez influenciam o treinamento.
  • Melhoria da previsão: o modelo se concentra nos padrões da maioria dos dados.
  • Estabilidade do treinamento: evita que o modelo se ajuste excessivamente a valores atípicos, melhorando a generalização.
  • Mascaramento de informação: se os outliers forem relevantes para a análise, substituí-los pode levar a conclusões errôneas ou à perda de insights.
  • Dificuldade de interpretação: os valores originais deixam de estar presentes nos dados de treino, o que torna crucial documentar a estratégia de imputação.
# imputação pela mediana
q1 = train['Age'].quantile(0.25)
q3 = train['Age'].quantile(0.75)
iqr = q3 - q1
lower_tail = q1 - 1.5 * iqr
upper_tail = q3 + 1.5 * iqr
med = np.median(train['Age'])

for i in train['Age']:
    if i > upper_tail or i < lower_tail:
        train['Age'] = train['Age'].replace(i, med)

4. Tratamento separado

Se houver um número significativo de outliers e o conjunto for pequeno, trate-os separadamente no modelo estatístico: construa modelos individuais para cada grupo e combine os resultados depois. A técnica é trabalhosa em conjuntos grandes.

Nem todas as técnicas mencionadas dão sempre o melhor resultado. Tenha cuidado ao detectar e substituir valores discrepantes.
